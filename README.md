# 🌍 Wanderlust – AI-Powered Travel Planner

An AI-powered full-stack travel planning application that helps users discover destinations, generate personalized travel itineraries, and manage their trips effortlessly. Powered by **Google Gemini AI**, Wanderlust provides intelligent travel recommendations based on user preferences while offering secure authentication and a modern, responsive user experience.

---

## ✨ Features

* 🤖 AI-powered travel recommendations using **Google Gemini AI**
* 🗺️ Personalized itinerary generation
* 🔍 Search and explore destinations
* 🔐 Secure authentication with **Google OAuth 2.0** and **JWT**
* 👤 Personalized user profiles
* 💾 Save and manage travel plans
* 📱 Responsive and modern user interface
* ☁️ Cloud deployment with **Vercel** (Frontend) and **Railway** (Backend)
